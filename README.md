# 像素场景装饰工坊

拖拽像素风美术素材、自由拼装场景的网页小游戏。纯前端、零构建依赖。

**在线试玩：https://decorator-game-six.vercel.app**

## 这是什么

素材来自一份 AI 游戏美术生产教程（Visual Bible → Master Scene → Production Sheet 的流程），
把教程里已经处理成"背景透明、单个物件独立"的素材表，用一个自己写的连通域检测脚本切成一个个
可摆放的透明贴图，再喂给这个网页装饰器。

两种玩法：
- **自由摆放**：从素材库把家具/道具/装饰拖进房间，自由布置、保存、导出成图。
- **拼图还原**（仅限"本来就是一张图切开"的素材，比如火锅摊那两张贴纸表）：打乱后手动拖回去，
  或者点"一键拼好"直接看标准答案。

## 功能

- 按主题 + 分类筛选的素材面板
- 拖拽新增 / 移动物件，支持网格吸附开关
- 按分类 + 纵坐标自动图层排序，选中物件可置顶 / 翻转 / 删除
- 房间尺寸自适应（有背景图的主题用背景图原始尺寸，否则手动设置）
- 布局保存到 localStorage，支持导出/导入 JSON 分享布局
- 导出整个房间为 PNG
- 内置一个从零写的"素材拆分器"（`splitter/`）：上传一张已经背景透明/纯色的贴纸表，自动做
  连通域检测切成独立文件，可以直接写入 `assets/production_sheets/`（需要 Chrome/Edge 的目录
  写入权限，其他浏览器退化成逐个下载）

## 本地运行

```bash
cd decorator-game
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

不能直接双击 `index.html` 打开——`fetch("assets/manifest.json")` 在 `file://` 协议下会被浏览器
CORS 挡住，必须过一个本地静态服务器。

## 加新素材

见 [AGENTS.md](./AGENTS.md) 的"素材命名规范"和"拆件工具"两节。简单说：

```
assets/production_sheets/<主题>/<分类>/<物件名>__<宽>x<高>.png
```

放好之后跑：

```bash
python tools/gen_manifest.py
```

## 技术栈

纯 HTML / CSS / 原生 JS，DOM + Pointer Events 做拖拽（不用 canvas 渲染物件，每个摆放的物件是一个
绝对定位的 `<img>`，方便单独选中/删层）。没有任何构建步骤和框架依赖。
